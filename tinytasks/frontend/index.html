TROUBLESHOOTING

Debug Tips

Run these commands from the directory containing docker-compose.yml.

Inspect services and logs

docker compose ps
docker compose logs --tail=100 api
docker compose logs --tail=100 db
docker compose logs --tail=100 ui

Common fixes

  • Port conflict: change the host side of the port mapping in docker-compose.yml.
  • Database authentication: check that POSTGRES_PASSWORD and DB_PASS match. Existing database volumes retain their initialized credentials.
  • Database startup race: keep the API dependency set to condition: service_healthy; the API also retries database initialization.
